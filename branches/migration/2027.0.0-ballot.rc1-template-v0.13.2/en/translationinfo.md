## Translation Information

 This page includes translations from the original source language in which the guide was authored. Information on these translations and instructions on how to provide feedback on the translations can be found [here](translationinfo.html). 

This guide is **German-language** (default language, "DE First" per the KDS governance §4.4 and the Release-2027 plan); **English** is the translation. Use the language switcher at the top right to change between `/de/` and `/en/`.

The English pages come from the module owners' English 2027 guide tree (a human translation, not machine translation); FHIR artifact identifiers stay English.
